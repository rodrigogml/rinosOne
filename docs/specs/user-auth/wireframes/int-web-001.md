# INT-WEB-001 — Entrada de acesso

```text
┌──────────────────────────────────────────────┐
│ Rinos One                                    │
│                                              │
│ Acesse sua conta                             │
│                                              │
│ [ Criar conta ] [ Entrar ]                   │
│                                              │
│ E-mail                                       │
│ [__________________________________________] │
│                                              │
│ (modo Entrar por senha)                      │
│ Senha                                        │
│ [__________________________________________] │
│                                              │
│ [ Entrar ]                                   │
│                                              │
│ [ ] Manter-me conectado                       │
│                                              │
│ ───────────────── ou ────────────────────── │
│ [ Receber link e código por e-mail ]         │
│                                              │
│ Mensagem de erro, sucesso ou limite          │
└──────────────────────────────────────────────┘
```

- A opção “Criar conta” remove o campo de senha e altera a ação principal para envio de validação; a escolha de persistência acompanha a emissão e é aplicada ao concluir a confirmação.
- Em telefone, a coluna ocupa a largura disponível e os controles mantêm espaçamento para toque.
