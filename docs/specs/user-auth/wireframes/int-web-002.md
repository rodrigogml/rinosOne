# INT-WEB-002 — Confirmação por e-mail

```text
┌──────────────────────────────────────────────┐
│ Confirme seu e-mail                           │
│ Enviamos um link e um código.                 │
│                                              │
│ Código de confirmação                         │
│ [ _ _ _ _ _ _ ]                               │
│ Válido por 10 minutos                         │
│ Manter-me conectado: Sim/Não                  │
│                                              │
│ [ Confirmar ]                                 │
│                                              │
│ Não recebeu? [ Reenviar mensagem ]            │
│                                              │
│ Após validar cadastro:                        │
│ Nome de exibição                              │
│ [__________________________________________] │
│ [ Concluir ativação ]                         │
│                                              │
│ Mensagem segura de erro, expiração ou sucesso │
└──────────────────────────────────────────────┘
```

- O bloco de nome aparece somente para ativação de conta, depois de confirmar link ou código.
- Um link aberto em outra aba chega a esta mesma jornada e mostra o próximo passo aplicável.
