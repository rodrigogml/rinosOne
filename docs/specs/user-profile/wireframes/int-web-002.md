## Recorte pronto para salvar

```text
┌──────────────────────── Imagem de perfil ────────────────────────┐
│ [x]                                                               │
│                                                                   │
│        ┌──────────────────────────┐   Zoom                       │
│        │                          │   [−] [==============] [+]  │
│        │    prévia e recorte      │   [Centralizar]              │
│        │         1:1              │                              │
│        │                          │   Setas: mover · +/-: zoom  │
│        └──────────────────────────┘                              │
│                                                                   │
│                 [Cancelar]              [Salvar imagem]          │
└───────────────────────────────────────────────────────────────────┘
```

No telefone, a prévia ocupa a largura possível antes dos controles, que se empilham abaixo. O diálogo permanece dentro da janela de Configurações e a imagem só é substituída após resposta confirmada.
