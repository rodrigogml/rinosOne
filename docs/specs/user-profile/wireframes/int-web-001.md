# INT-WEB-001 — Perfil nas Configurações

## Desktop e tablet largo

```text
┌────────────────────────── Configurações do usuário ─────────────────────────┐
│ [x]                                                                          │
├───────────────────────┬─────────────────────────────────────────────────────┤
│ Configurações         │ Perfil                                              │
│                       │ Mantenha a identidade exibida na plataforma.         │
│ › Perfil              │                                                     │
│   Tema e aparência    │ ┌─ Identidade ─────────────────────────────────────┐ │
│   Sessões             │ │   (avatar)  Imagem atual                         │ │
│   Segurança           │ │             [Alterar imagem] [Remover imagem]    │ │
│                       │ └─────────────────────────────────────────────────┘ │
│                       │                                                     │
│                       │ ┌─ Nome ──────────────────────────────────────────┐ │
│                       │ │ Nome                                              │ │
│                       │ │ [ Ana Souza____________________________________ ] │ │
│                       │ │                          [Salvar alterações]     │ │
│                       │ └─────────────────────────────────────────────────┘ │
├───────────────────────┴─────────────────────────────────────────────────────┤
│ Área de trabalho e taskbar permanecem fora da janela                         │
└─────────────────────────────────────────────────────────────────────────────┘
```
