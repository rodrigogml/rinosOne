# INT-WEB-SHELL-002 — Menu pessoal

```text
                         ┌──────────────────────────────┐
                    [AV] │ Configurações do usuário      │
                         │ (destino reservado)           │
                         ├──────────────────────────────┤
                         │ [ paleta ] [ idioma ] [ sair ] │
                         └──────────────────────────────┘
```

O menu ancora no avatar em desktop e móvel. A parte inferior é visualmente separada: paleta abre as preferências visuais existentes, idioma abre o seletor existente e sair encerra a sessão pelo fluxo existente.
