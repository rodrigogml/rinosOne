# INT-WEB-SHELL-001 — Casca autenticada e barra superior

```text
Desktop
┌──────────────────────────────────────────────────────────────────────────────┐
│ [ logo paisagem reduzido ]                                      [ avatar ]   │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  Conteúdo da área autenticada atual                                          │
│  (nesta fase: segurança de acesso)                                           │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

Telefone
┌──────────────────────────────────────┐
│ [ logo paisagem / abre navegação ] [avatar] │
├──────────────────────────────────────┤
│                                      │
│  Conteúdo autenticado                │
│                                      │
└──────────────────────────────────────┘
```

A barra é a única região persistente. Em desktop, a marca é apenas identidade; em telefone, o logo paisagem também abre o painel de navegação, sem aparência visual de botão. O conteúdo principal não cria uma segunda barra própria.
