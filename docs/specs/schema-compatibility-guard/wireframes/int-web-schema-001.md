# INT-WEB-SCHEMA-001 — Wireframe de baixa fidelidade

A estrutura ilustra a página segura; o texto de [interface-spec.md](../interface-spec.md) é a fonte de verdade.

## Desktop, tablet e telefone

```text
┌─────────────────────────────────────────────────────┐
│                    [ marca Rinos One ]               │
│                                                     │
│               Atualização em andamento               │
│                                                     │
│  A plataforma está temporariamente indisponível      │
│  para atualização.                                  │
│                                                     │
│                [ Tentar novamente ]                 │
└─────────────────────────────────────────────────────┘
```

- Não há menu, avatar, seletor de organização, conteúdo funcional ou dados de sessão.
- Em telefone, a coluna usa as margens seguras e o botão mantém largura alcançável.
- O título recebe foco inicial e a ação fica depois da descrição na ordem de leitura.
