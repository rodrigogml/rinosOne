# Interface do usuário

- Para qualquer alteração de interface Vue, controles, formulários, diálogos ou mensagens, use a skill local `rinos-ui-development` em `.agents/skills/rinos-ui-development/` antes de implementar.
- A rota `/dev` do sistema é a fonte de verdade para aparência, tokens visuais e padrões de componentes da UI. Qualquer divergência entre essa rota e a documentação de especificação deve ser reportada ao usuário antes da implementação, para correção e mitigação; não presuma qual referência prevalece enquanto a divergência não for resolvida.
